# Símbolos das Disciplinas

Gabriel forneceu o pacote `Vampire Discipline Symbols` ao projeto em 21/11/2026. Os originais Illustrator e suas prévias PNG foram recebidos na pasta local `documentacao/05-planejamento/Vampire Discipline Symbols/`. A data de download original e os termos de redistribuição não constam no pacote.

Os SVGs são exportações da página vetorial incorporada aos arquivos Illustrator, obtidas com `page.get_svg_image()` do PyMuPDF. Preservam a prancheta, as cores e os traçados originais. O CSS integra os símbolos ao papel e ajusta a apresentação no seletor e no cabeçalho da Disciplina. Cada arquivo público usa o nome após `discipline:` acrescido de `.svg`.
