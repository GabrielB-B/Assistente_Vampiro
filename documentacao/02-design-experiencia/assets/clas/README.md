# Ativos visuais dos clãs

As 14 composições em `paletas-originais/` vieram do pacote fornecido por Gabriel em
`Material 3 - Paleta de cores dos clãs`. Elas são a fonte visual aprovada para símbolo e
paleta; não são ilustrações geradas pelo produto.

`extract-clan-symbols.ps1` isola, por cor e recorte determinísticos, os símbolos já
presentes nessas composições. O script não redesenha nem sintetiza formas. As saídas
transparentes ficam em `apps/web/public/images/clans/`.

Caitiff e Sangue-Ralo não recebem símbolo substituto: a interface usa somente seus nomes.
